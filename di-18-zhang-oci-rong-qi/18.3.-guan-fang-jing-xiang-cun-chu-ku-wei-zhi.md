# 18.3.官方镜像存储库位置

与架构无关的镜像可以从[官方 FreeBSD 发行版](https://download.freebsd.org/releases)网站下载并直接导入你自己的注册表，也可以从 FreeBSD 项目的 [Docker Hub](https://hub.docker.com/u/freebsd) 或 [GitHub Container Registry](https://github.com/orgs/freebsd/packages) 拉取。

[Alpine Linux](https://hub.docker.com/_/alpine/) 和 [Debian](https://hub.docker.com/_/debian/) 项目都以类似的方式发布带标签的可变镜像。
