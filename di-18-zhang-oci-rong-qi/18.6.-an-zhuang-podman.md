# 18.6.安装 Podman

只需 [sysutils/podman-suite](https://cgit.freebsd.org/ports/tree/sysutils/podman-suite/) 元软件包。不过，如果另外安装 [emulators/qemu-user-static](https://cgit.freebsd.org/ports/tree/emulators/qemu-user-static/) 软件包，就可以在 amd64 主机上构建或测试 arm64 等其他架构的镜像。

```sh
# pkg install -r FreeBSD -y podman-suite emulators/qemu-user-static
```
