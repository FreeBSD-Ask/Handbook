# 18.12.网络与名称解析

默认情况下，Podman 工具套件会使用 [mount_nullfs(8)](https://man.freebsd.org/cgi/man.cgi?query=mount_nullfs&sektion=8&format=html) 挂载来自 jail 主机的 **/etc/resolv.conf** 和修改过的 **/etc/hosts**，以及 **/var/run** 下的 `.containerenv` 文件。

这个 hosts 文件会与基本系统软件包升级冲突，因此建议在 `podman build` 运行时跳过它，而在生产部署时保持启用：

```sh
# podman run --dns 1.2.3.4 ...
# podman build --no-hosts ...
```

`--dns` 选项指定自定义 DNS 服务器，而不是从主机挂载 **/etc/resolv.conf**。`--no-hosts` 选项阻止从主机挂载 **/etc/hosts**。
