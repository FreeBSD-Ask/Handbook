# 18.10.导入并运行容器

> **注意**
>
> 目前，FreeBSD 上的所有 Podman 容器都必须以 root 身份运行，这是 FreeBSD jail 的要求。

在必要的工具和防火墙规则就位后，就可以从 [FreeBSD Releases](https://download.freebsd.org/releases/OCI-IMAGES/) 获取官方发布的镜像，并根据情况选择 [aarch64](https://download.freebsd.org/releases/OCI-IMAGES/15.1-RELEASE/aarch64/Latest/) 或 [amd64](https://download.freebsd.org/releases/OCI-IMAGES/15.1-RELEASE/amd64/Latest/)。

## 18.10.1. 导入 FreeBSD OCI 镜像

如上所述，虽然直接从公共容器注册表拉取镜像最为方便，但为了获得最强的信任链，请直接从 [FreeBSD.org](https://download.freebsd.org/releases) 下载镜像，并根据 PGP 签名的发行公告校验校验和。

```sh
# export OCIBASE=https://download.freebsd.org/releases/OCI-IMAGES/15.1-RELEASE/amd64/Latest
```

## 18.10.4. 使用公共注册表

虽然最安全的来源是从[官方 FreeBSD 发行版](https://download.freebsd.org/releases)下载，但还有两个由 FreeBSD 发行团队和集群管理员团队管理的公共容器注册表。两者提供的镜像完全相同，但工作流更简单，也更贴合容器的使用方式。

* [Docker Hub](https://hub.docker.com/u/freebsd)
* [GitHub Container Registry](https://github.com/orgs/freebsd/packages)

## 18.10.5. 获取容器

可以使用 `podman pull` 从公共注册表获取镜像：


## 18.10.6. 运行容器

使用 `podman run` 启动容器。`-it` 选项分配一个交互式终端，`--rm` 在容器退出时将其删除。如果未指定命令，则使用镜像的默认入口：

```sh
# podman run -it --rm ghcr.io/freebsd/freebsd-notoolchain:15.1
# exit
```

也可以指定具体的命令：

```sh
# podman run -it --rm ghcr.io/freebsd/freebsd-notoolchain:15.1 uname -a
FreeBSD c0038de70651 15.1-RELEASE FreeBSD 15.1-RELEASE releng/15.1-n283562-96841ea08dcf GENERIC amd64
```

由于容器镜像不包含内核，[freebsd-version(1)](https://man.freebsd.org/cgi/man.cgi?query=freebsd-version&sektion=1&format=html) 对运行中的内核与已安装的用户空间会显示不同的结果。本例中，15.0-RELEASE 容器运行在 15.1-RELEASE 主机上：

```sh
# podman run -it --rm ghcr.io/freebsd/freebsd-notoolchain:15.0 /bin/sh
# freebsd-version -ru
15.1-RELEASE
15.0-RELEASE
# exit
```
